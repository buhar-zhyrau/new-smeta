# Смета за 5 минут

Веб-приложение для быстрого составления сметы или коммерческого предложения и сохранения результата в PDF.

Для кого:
- предприниматели — подготовить коммерческое предложение клиенту;
- офисные сотрудники — составить смету закупки или расчёт расходов для руководителя.

## Файлы приложения

Планируемая структура (файлы приложения пока не созданы):
- `index.html` — структура страницы, поля ввода и кнопки;
- `styles.css` — оформление и удобное отображение на компьютере и телефоне;
- `script.js` — расчёт сумм и логика работы приложения, включая сохранение в PDF.

## Как открыть

Когда появятся файлы приложения, дважды щёлкните по `index.html`, чтобы открыть его в браузере. Установка программ и запуск сервера не требуются.

## Как проверить

Когда будет реализован расчёт, добавьте две позиции:
- количество `2`, цена `15 000 ₸`;
- количество `1`, цена `8 000 ₸`.

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.
